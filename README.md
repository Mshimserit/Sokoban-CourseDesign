# Sokoban - 推箱子游戏

基于 Java Swing 的经典推箱子游戏，支持多关卡、关卡编辑器、排行榜和死局检测。

## 功能特性

- **多关卡游戏**：内置 7 个关卡，支持关卡切换
- **键盘控制**：方向键移动，支持撤销操作
- **实时统计**：显示当前关卡、步数和用时
- **关卡编辑器**：可视化设计关卡并保存
- **排行榜**：记录每关最少步数，支持历史最佳
- **死局检测**：箱子推入角落时自动提示
- **数据持久化**：关卡和成绩本地保存

## 技术栈

- Java 17
- Swing（图形界面）
- JUnit 5（单元测试）

## 项目结构

```
src/
├── logic/              # 应用逻辑层
│   ├── GameEngine.java     # 游戏引擎（移动、撤销、死局检测）
│   ├── GameMap.java        # 游戏地图（地图解析、完成判断）
│   ├── Level.java          # 关卡数据
│   ├── LevelManager.java   # 关卡管理（加载、切换）
│   └── ScoreRecord.java    # 分数持久化
└── ui/                 # 用户界面层
    ├── MainFrame.java      # 主窗口
    ├── GamePanel.java      # 游戏渲染面板
    ├── LevelEditor.java    # 关卡编辑器
    └── LeaderboardDialog.java # 排行榜
```

## 快速开始

### 运行游戏

```bash
bin\run.bat
```

### 编译项目

```bash
bin\compile.bat
```

### 打包 JAR

```bash
bin\build_jar.bat
```

### 运行测试

```bash
bin\compile_test.bat
bin\run_test.bat
```

## 地图元素

| 元素 | 值 | 说明 |
|------|-----|------|
| 空地 | 0 | 可通行 |
| 墙   | 1 | 不可通行 |
| 箱子 | 2 | 可推动 |
| 目的地 | 3 | 箱子目标位置 |
| 玩家 | 4 | 玩家位置 |
| 箱子在目的地 | 5 | 箱子已归位 |

## 操作说明

| 按键 | 功能 |
|------|------|
| 方向键 ↑↓←→ | 移动玩家/推箱子 |
| Ctrl+Z | 撤销上一步 |
